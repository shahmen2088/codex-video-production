# Video production

1. Зафиксировать цель, аудиторию, длительность, формат кадра, доказуемые функции продукта и запреты на раскрытие данных.
2. Сначала подготовить сценарий и раскадровку с таймкодами; отдельно перечислить, что реально показано в интерфейсе.
3. Подготовить ассеты с понятными именами: экранные записи, логотип, музыка/озвучка, субтитры. Не использовать чужие медиа без лицензии.
4. Для монтажа предпочитать воспроизводимые команды FFmpeg; сохранять исходники и промежуточные файлы отдельно от финального экспорта.
5. Проверить громкость, читаемость субтитров, safe area, отсутствие лишних окон/секретов и соответствие сцен сценарию.
6. Передать handoff-пакет: brief, script, storyboard, manifest, checksums, команды сборки и список известных ограничений.

## Пример

Для 90-секундной презентации Control Center: 0–10 с проблема, 10–25 с обзор, 25–65 с три доказуемых сценария, 65–80 с результат, 80–90 с финальный призыв. Каждая сцена должна иметь источник записи и критерий приёмки.
